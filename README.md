# Lungelo Mokoena Attorneys — website files

This folder has everything needed for the site: `index.html`, `styles.css`, `script.js`.

## Before you publish — fill these in
Open `index.html` and search for:
- `info@mokoenalaw.com` — replace if this isn't the right inbox
- `Add your number` — your office phone number
- `Add your office address` — your physical/postal address
- `Add your consulting hours` — e.g. "Mon–Fri, 8am–5pm"
- The newsletter signup form is just a placeholder — it doesn't send emails anywhere yet. To make it work for free, sign up at a service like Mailchimp or Buttondown and paste in the embed code they give you.

## Hosting it for free — GitHub Pages
1. Create a free account at github.com if you don't have one.
2. Create a new repository (e.g. `mokoenalaw-site`).
3. Upload these three files (`index.html`, `styles.css`, `script.js`) using the "Add file → Upload files" button in the repo.
4. Go to the repo's **Settings → Pages**.
5. Under "Branch," choose `main` and folder `/root`, then Save.
6. GitHub will give you a live link, usually `https://yourusername.github.io/mokoenalaw-site/`, live within a minute or two.
7. You can later point your existing mokoenalaw.com domain at this for free too (GitHub Pages supports custom domains — just add a `CNAME` file with your domain in it, and update your domain's DNS settings).
